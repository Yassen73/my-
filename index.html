    عند ظهور نافذة الطباعة: الوجهة «حفظ كـ PDF»، الهوامش «بدون»، وفعّل «رسومات الخلفية». الخطوط تُدمج تلقائيًا في الملف.

    التصدير
    ربط الذكاء الاصطناعي

    ضع مفتاح Gemini المجاني في CONFIG.apiKey أعلى الكود. للنشر الحقيقي اربط هنا Worker حتى لا يظهر مفتاحك لأي زائر.

    كود الـ Worker (ضع المفتاح في ANTHROPIC_API_KEY)
    export default{async fetch(r,env){
const h={'access-control-allow-origin':'*','access-control-allow-headers':'content-type'};
if(r.method=='OPTIONS')return new Response(null,{headers:h});
const b=await r.json();
const x=await fetch('https://api.anthropic.com/v1/messages',{method:'POST',headers:{'x-api-key':env.ANTHROPIC_API_KEY,'anthropic-version':'2023-06-01','content-type':'application/json'},body:JSON.stringify({...b,model:b.model||'claude-sonnet-5-5'})});
return new Response(await x.text(),{status:x.status,headers:{...h,'content-type':'application/json'}})}}
